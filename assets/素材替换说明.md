当前角色、陶罐与背景由独立 GDI 几何图形绘制，不使用原游戏素材。音频为程序合成的试作音频。

可选替换图片：使用24位BMP，不安装额外软件即可用Windows画图另存为此格式。要透明的区域填纯洋红色 RGB(255,0,255)。必须按指定尺寸制作：

| 文件名 | 像素尺寸 |
|---|---|
| pot_blue.bmp / pot_white.bmp / pot_beige.bmp / pot_brown.bmp | 58×49 |
| character_idle.bmp / character_attack.bmp / character_hit.bmp / character_fail.bmp / character_win.bmp | 190×240 |
| background.bmp | 1280×720 |

将文件放在此 assets 文件夹，重新启动游戏即可。没有图片时继续显示默认图形。当前 patterned 陶罐共用基础替换图；以后可增加独立纹样素材槽。

15列版仍使用以上原始图片尺寸。陶罐显示时按完整58×49源图等比缩小到50×42并对齐格子底部，角色和背景尺寸不变。无需把陶罐素材手动裁成50×42。
